Tilari for macOS

Open Tilari.app (from the unzipped folder). A browser opens on
http://127.0.0.1:8000/ (or the next free port).

From Terminal:
  Tilari.app/Contents/MacOS/Tilari --no-browser --port 18080

Unsigned builds: first open may need right-click → Open (Gatekeeper).
Notarization / Developer ID signing is not part of this pack.

This is a local desktop pack, not a VPS server.
