Tilari for Windows (portable)

Double-click Tilari.exe (or Tilari.cmd). A browser opens on
http://127.0.0.1:8000/ (or the next free port; see the console).

Useful flags (pass to Tilari.exe / Tilari.cmd):
  --no-browser
  --port 18080
  --lan

This is a local desktop pack, not a VPS server. Keep the whole folder
together; do not move Tilari.exe alone.

Unsigned binary: SmartScreen may warn on first run — choose "More info"
then "Run anyway" if you built or trust this zip.
